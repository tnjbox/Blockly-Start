課程管理：線上匯入課程 JS 檔

把新的課程 JS 檔匯入到你自己這一份網站——會直接透過 GitHub API commit 進你的 repo， 幾分鐘後 GitHub Pages 重新部署完成，網站上就會出現新課程。這一頁只有你自己（網站的 擁有者）看得到效果，不需要任何 Cloudflare 或 Google 帳號，只需要一組你自己 GitHub 帳號的存取權杖（token）。

1. 連接你的 GitHub Repo

沒有 Token？怎麼建立一個？
  1. 登入 GitHub，前往 Settings → Developer settings → Personal access tokens → Fine-grained tokens 。
  2. Repository access 選「Only select repositories」，勾選你複製出來的這個repo。
  3. Permissions 底下的 Contents 設為 Read and write，其他保持預設即可。
  4. 建立後把 token 貼到上面欄位——這個 token 只會存在你自己這台瀏覽器的 localStorage，不會送到我們（或任何第三方）手上。
